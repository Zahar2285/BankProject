# Банковский виджет

## Описание проекта

Проект предназначен для обработки банковских операций клиента.

Реализованы следующие функции:

- маскировка номеров банковских карт;
- маскировка номеров счетов;
- определение типа платежного инструмента;
- преобразование даты из ISO-формата;
- фильтрация операций по статусу;
- сортировка операций по дате;
- поиск операций по категории и описанию;
- поиск операций с номерами телефонов;
- поиск переводов физическим лицам;
- формирование отчетов по банковским операциям;
- получение курсов валют;
- получение котировок акций.

## Установка

Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейдите в директорию проекта:

```bash
cd project
```

Установите зависимости:

```bash
poetry install
```

## Запуск

Для запуска проекта используйте:

```bash
poetry run python -m src.main
```

## Тестирование

Запуск тестов:

```bash
poetry run pytest
```

Проверка покрытия:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Проверка качества кода:

```bash
poetry run flake8 .
```

Проверка типизации:

```bash
poetry run mypy src
```

## Переменные окружения

Для работы с API необходимо создать файл `.env` и указать API-ключ:

```text
API_KEY=your_api_key
```

Файл `.env` не должен добавляться в Git.
